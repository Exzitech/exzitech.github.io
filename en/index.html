02 Projects

Each project has its own public repository: the code, the tests and a README that explains the decisions.

Desktop application

Tauri · Rust · React · Python

ExziHub, an app where every tool is a plugin

The foundation for the other projects. Tools are installed, updated and removed from an online catalogue, without downloading the app again. A plugin can ship its own Python engine, which the hub starts and monitors. The same code runs on Windows and Android.

  • About 13 MB, versus over 100 with Electron.
  • Packages checked against a SHA-256 hash before installing.
  • Sync across devices without overwriting a change made elsewhere.

Code and architecture

Data extraction

Python · Tesseract · WebSocket

Reading a screen in real time, never counting twice

An engine reads part of the screen continuously and turns it into structured events, each counted exactly once, even when the display scrolls, repeats itself or is misread. Example: the real cost of a restaurant's dishes, read from its wholesaler's ordering software, which offers no API.

  • Deduplication by position, tolerant of reading errors.
  • Anything ambiguous is set aside, never counted by default.
  • Real sessions replayed offline, 120 tests.

Decision support

TypeScript · Web Worker · Monte-Carlo

Breeding planner, planning by simulation

When every decision has a random outcome, the tool simulates hundreds of runs for each option, all on the same random draws: the measured difference comes from the choice, not from luck. The model is calibrated on real data and runs off the main thread, in under a second.

04 How I work

Understand before writing. The real need first, then the simplest solution that meets it, with no needless dependencies.

Test what matters. Business logic is kept apart from the interface and covered by tests; every fixed bug leaves a test behind.

Measure before optimising. A baseline, one change at a time, a new measurement.

Leave something maintainable. Readable code and documentation that describes the actual state, so you can take it over without me.
